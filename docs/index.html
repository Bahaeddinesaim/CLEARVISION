Deploy-ready structure

Run the interactive app locally

streamlit run app.py --server.address 0.0.0.0 --server.port 8502

Then open http://10.68.247.21:8502 from another device on the same network.

GitHub Pages is static. The real Streamlit app needs a Python server, Streamlit Community Cloud, Docker, Render, Railway, Hugging Face Spaces or your local machine.
